# Заказы с сайта в Telegram

Сайт отправляет заказ в бесплатную функцию Cloudflare Workers (`worker.js`),
а она пересылает его в Telegram. Токен бота хранится только в Cloudflare,
на сайте его нет. Если функция недоступна, покупатель отправляет заказ
вручную (Telegram или почта) — заказ не теряется.

## Запуск (≈10 минут)

1. **Бот.** В Telegram откройте @BotFather → `/newbot` → придумайте имя и
   адрес бота (должен заканчиваться на `bot`). Сохраните токен. Никому его не пересылайте.
2. Откройте своего нового бота и нажмите **Start** — иначе он не сможет вам писать.
3. **Ваш id.** Откройте @userinfobot → Start. Он пришлёт число `Id` — это CHAT_ID.
   Для общего чата флористов: добавьте бота в группу, CHAT_ID группы начинается с `-`.
4. **Cloudflare.** Зарегистрируйтесь на dash.cloudflare.com (бесплатно) →
   Workers & Pages → Create → Worker → «Hello World» → имя `teplica-orders` → Deploy.
5. **Edit code** → удалите всё → вставьте содержимое `bot/worker.js` → Deploy.
6. **Settings → Variables and Secrets → Add:**
   - `BOT_TOKEN` — тип **Secret**, значение — токен из шага 1;
   - `CHAT_ID` — ваш id (можно несколько через запятую);
   - `ALLOWED_ORIGINS` — `https://suvkovivan-cpu.github.io` (после подключения домена добавьте его через запятую).
   Нажмите Deploy.
7. Скопируйте адрес функции вида `https://teplica-orders.<ваше-имя>.workers.dev`
   и впишите его в `index.html` в строку `const ORDER_ENDPOINT = "";`.

Проверка: откройте адрес функции в браузере — должно быть «Teplica order bot: OK».
Затем оформите тестовый заказ на сайте: он придёт в Telegram.

## После продажи студии
Поменяйте `CHAT_ID` на id владельца или чата флористов — заказы пойдут им.
Лучше, чтобы студия завела своего бота и свой аккаунт Cloudflare.
